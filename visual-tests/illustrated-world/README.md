# НОВАЯ ЖИЗНЬ — новая графика всех экранов

Ветка `design/illustrated-world` продолжает одобренное оформление фермы из
`design/blue-farm`. Новая графика подготовлена для всех используемых интерфейсом
изображений; одобренная HD-сцена фермы сохранена.

## Что изменилось

- **28 новых самостоятельных изображений** в `assets/illustrated/`: пять
  иллюстраций (курятник, рынок, магазин, сундук, склад), персонажи и ресурсы,
  деньги, здания и значки навигации. Сцены и прозрачные предметы созданы заново,
  а не увеличены из старых маленьких обрезок.
- Новые аватар, курица, цыплёнок, зерно, яйцо и пара яиц, монета и стопки монет,
  кристалл, мешок корма, сердце, амбар, курятник, магазин, рыночный прилавок,
  склад, инкубатор, ящик, кошелёк, профиль, задания, дом и статистика.
- Полноценные прозрачные значки без подписей, фоновых плиток и соседних объектов.
  Навигация больше не вырезается из старого атласа. Подписи и кнопки — HTML.
- У сцен настроено кадрирование и мягкий переход к фону панелей. Убрана
  дополнительная курица поверх сундука в наборе; сундук стал частью оформления.
- WebP сохраняет исходные размеры (см. `assets/illustrated/manifest.json`).
  Оригиналы генерации сохранены в рабочей среде, старый пакет не удалён.
- Все экранные изображения, включая скрытые вкладки и окна покупки, подключены
  к новым файлам. Старые файлы остаются в репозитории для совместимости.

Изменены `index.html`, только пути изображений/декодирование в `assets/game.js`,
визуальные правила `assets/game.css`, QA-скрипты и новые графические файлы.
Схема БД, `main.py`, цены, API, баланс, производство, токен авторизации и история
операций не изменены. Хеш `main.py` остался:
`9a1f07bb7805099474e293ea20f52da836f4b2c587caec5888920993b2a5e493`.

## Проверки

- Все **187 PNG/WebP** (старый пакет, HD-ферма, новые изображения) отвечают
  HTTP 200 с `image/*`, успешно декодируются Chromium.
- **7 regression-тестов** на отдельной локальной PostgreSQL 17 прошли.
- **40 проверок** экранов на 320/375/390/430 px прошли: нет горизонтального
  переполнения, нижняя навигация не закрывает последние элементы управления.
- Реальные регистрация/сохранение входа, покупки, продажа/возврат товара,
  автозакупка, суточное производство и пропорциональный рынок прошли.
  Общая эмиссия в тестовой базе осталась 10 000 монет.
- Ошибок JavaScript и изображений нет. Ruff, `node --check` и `git diff --check`
  проходят. Остаётся известное предупреждение Starlette/AnyIO, не связанное с артом.

Тесты работают только с отдельными локальными QA-базами, без сброса/удаления
данных. Production/Railway не изменялись. Инкубатор и платежи остаются
недоступными — новые картинки не добавляют выдуманных операций.

## Повторение проверки

Запустить существующий сервер на локальной QA-базе, как описано в
`visual-tests/browser_qa.py`, затем:

```sh
python visual-tests/check_assets.py
FARM_VISUAL_TEST_DATABASE_URL=postgresql://farm:farm@127.0.0.1:5543/farm_visual_regression_test \
  python -m pytest -q visual-tests/test_regression.py
FARM_VISUAL_OUTPUT=/workspace/artifacts/illustrated-world \
  python visual-tests/browser_qa.py
```

Браузерная проверка ожидает декодирование крупных изображений перед снимком.
Финальные кадры дополнительно сняты `visual-tests/capture_screens.py` в свежих
страницах Chromium с тем же настоящим QA-аккаунтом, без повторных операций.
В облачном headless Chromium используется программная отрисовка для стабильных
скриншотов. Это не меняет код игры или её механику.

Слияние и публикация в production — только после одобрения владельца.
