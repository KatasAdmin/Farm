# «НОВАЯ ЖИЗНЬ — ФЕРМА»: визуальное обновление V3

Ветка: `design/asset-pack-v3`. Черновик PR: https://github.com/KatasAdmin/Farm/pull/1

Графика из пользовательского ZIP установлена в `assets/`: 79 отдельных изображений
в PNG и WebP, исходный `asset-manifest.json`. Сцены, персонажи, здания, ресурсы,
монеты и кристаллы подключены к реальному интерфейсу. Атлас и изображения целых
экранов не используются. Нарисованные кнопки не используются: управление — HTML,
подписи — текст, навигационные плитки обрезаются CSS до отдельных иконок.

## Изменённые файлы

- `index.html`: ферма, курятник, рынок (купить/продать), магазин, кошелёк,
  профиль, склад, задания-цели, улучшения; настоящий диалог покупки с количеством.
- `assets/game.css`: компактный мобильный интерфейс, зелёные игровые панели,
  настоящие градиентные кнопки, декоративные сцены, safe-area и место под навигацию.
- `assets/game.js`: существующие API и ключ `farm_token`; покупки, торговля,
  возврат резервов, настройки автозакупки, реальные ресурсы и история операций.
- `assets/{backgrounds,buildings,characters,currency,objects,ui}/`: все 158 файлов
  PNG/WebP из ZIP. `assets/asset-manifest.json`: исходный каталог.
- `assets/fonts/RobotoCondensed.ttf`, `assets/fonts/OFL.txt`: локальный шрифт
  Roboto Condensed из Google Fonts, лицензия SIL OFL. Внешних CDN при игре нет.
- `visual-tests/`: проверки API, браузера, загрузки ресурсов, отчёты и скриншоты.
- `.gitignore`: локальная среда, кэш Python/pytest и `.env`.
- Этот документ: результат интеграции и инструкции проверки.

`main.py`, `requirements.txt`, Dockerfile, схема БД и экономические правила
**не изменены**. SHA-256 `main.py`:
`9a1f07bb7805099474e293ea20f52da836f4b2c587caec5888920993b2a5e493`.

Production и Railway не запускались и не изменялись. Тесты работают только
с отдельным локальным PostgreSQL на порту 5543. Данные не сбрасывались: новые
тестовые аккаунты создаются через API. Для проверки суточного цикла изменяется
только `last_tick` этих специально созданных аккаунтов, а не ресурсы или баланс.

## Что проверено

- **7 regression-тестов прошли** на PostgreSQL 17: регистрация/авторизация,
  сохранение эмиссии, цены 30/2, казна и история, суточное производство,
  автозакупка, пропорциональный выкуп, возврат товара и отклонённые покупки.
- **40 браузерных проверок**: все экраны на 320/375/390/430 px, без
  горизонтального переполнения; последние элементы доступны над нижней навигацией.
- Реальные действия Chromium: регистрация и сохранение входа после reload,
  10 зерна за 20 монет, курица за 30, продажа/отмена, автозакупка вкл./выкл.,
  расход 2 зерна → 2 яйца за сутки. Выкуп 4 яиц из пулов 2:6 распределился 1:3.
- Общая сумма монет игроков и казны осталась **10 000**.
- Все **158 PNG/WebP**: HTTP 200, `image/*`, успешное декодирование Chromium.
- Ошибок JavaScript и изображений нет. `node --check`, Ruff и `git diff --check`
  прошли. Зависимость Starlette/AnyIO выдаёт предупреждение DeprecationWarning;
  производственные зависимости для визуальной задачи не обновлялись.

Подробности: [browser-report.json](visual-tests/browser-report.json),
[аудит качества ресурсов](visual-tests/ASSET_AUDIT.md).

## Оставшиеся отличия от эталона

- В пакете исходная сцена фермы — 300×200, а в эталоне более подробная высокая
  иллюстрация. Масштабирование и кадрирование не восстанавливают недостающие детали.
- У ряда спрайтов дефекты вырезания и alpha. Неудачные предметные `*_icon`,
  подарки и трофей не используются; заменены более чистыми ресурсами из архива.
  У куриц и кристаллов остаются небольшие дефекты маски. Перечень файлов и
  необходимых замен — в `visual-tests/ASSET_AUDIT.md`.
- Суточный цикл сохранён: надпись «раз в 12 часов» из эталона не перенесена.
- Нет выдуманных уровней, XP, лимитов склада/курятника, денежных наград за задания,
  скидок и дополнительных предметов в наборе. Набор остался **3 курицы + 30 зерна
  за 150 монет**, как в сервере. Яйца покупаются у игроков, а не у системы.
- Продажа куриц, инкубация и покупка вместимости сервером не поддерживаются.
  Улучшения ведут к настоящей покупке курицы и автозакупке; инкубатор обозначен
  недоступным, без списания монет. На рынке только поддерживаемые зерно и яйца.
- Пополнение/вывод отключены; курс реальных валют не показывается. Кристаллы —
  декоративная отметка «—», без фиктивного кошелька и операций.
- Существующая авторизация по ключу браузера сохранена. Пароли/восстановление
  отсутствуют в текущем сервере; интерфейс предупреждает о последствиях выхода.

## Воспроизведение QA

Не направлять эти проверки на production. Установить Python 3.12, Chromium
(`/usr/bin/chromium`), PostgreSQL 17 и зависимости:

```sh
pip install -r requirements.txt -r visual-tests/requirements.txt
```

Используются отдельные локальные БД `farm_visual_test` и
`farm_visual_regression_test`, пользователь/пароль `farm`, порт `5543`.
Их следует создать пустыми в отдельном экземпляре PostgreSQL; существующие
базы переименовывать или сбрасывать не нужно.

```sh
FARM_VISUAL_TEST_DATABASE_URL=postgresql://farm:farm@127.0.0.1:5543/farm_visual_regression_test \
  python -m pytest -q visual-tests/test_regression.py
DATABASE_URL=postgresql://farm:farm@127.0.0.1:5543/farm_visual_test \
  uvicorn main:app --host 127.0.0.1 --port 8085
# В другом терминале:
python visual-tests/check_assets.py
python visual-tests/browser_qa.py
```

Скриншоты и JSON браузерной проверки записываются в
`/workspace/artifacts/farm-v3/`. Каждый прогон создаёт уникальные QA-аккаунты из
реального тестового фонда; сохраняет их данные для осмотра, ничего не удаляет.

**PR остаётся черновиком. Слияние и production-развёртывание — только после
одобрения владельца.**
