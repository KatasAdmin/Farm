# Бот «Новая жизнь»

Бот: https://t.me/Farmlife2026bot. Отправить /start, чтобы увидеть постоянную клавиатуру.

Меню: Заработать | Продвижение; Игры | Мой кабинет; Партнёры | О боте.
В играх пока только ферма. Кубик и цвета не реализованы.

## Задания

Рекламодатель: Продвижение → тип задания → название → инструкция → ссылка → награда в гривнах → количество выполнений → подтвердить. Бюджет списывается с его рекламного баланса целиком и резервируется в задании. Если на рекламном балансе недостаточно средств, задание не создаётся. Комиссия первой версии — ноль. До модерации задание не показывается исполнителям.

Каналы и группы проверяются через getChatMember; наш бот должен быть администратором целевого чата. Исполнитель сначала берёт задание, затем вступает, потом нажимает Проверить. Уже состоящий в чате пользователь получить награду за эту подписку не может. Автопроверка проверяет членство в момент начисления; длительность удержания подписки не обещается.

Ручное задание: взять → выполнить → Проверить → отправить текст или одно фото. В Продвижении рекламодатель открывает Проверить работы, принимает либо отклоняет. Отправка доказательства не начисляет деньги автоматически. Задание с ожидающими проверки работами нельзя закрыть. Остаток бюджета возвращается на рекламный баланс владельца при закрытии или отклонении модерацией. Уже выплаченные награды не возвращаются владельцу.

## Кабинет и переводы

Основной баланс — заработок, переводы с фермы и средства для вывода. Рекламный баланс — свободные деньги для создания заданий. «Конвертировать» переводит свободные средства между ними 1:1 без комиссии; деньги в бюджете уже созданного задания недоступны для конвертации. Существующие основные балансы сохраняются; рекламный баланс при миграции начинается с нуля.

Кабинет показывает реальные пополнения, расходы на оплаченные выполнения, заработок, оставшийся резерв заданий, ожидающие выплаты и уже выплаченные суммы. Созданный бюджет и фактически израсходованный бюджет показываются отдельно.

Все гривневые суммы хранятся целым числом копеек. Два знака после запятой, без округления float. Stars имеют собственный существующий учёт и не смешиваются с гривнами.

Бот → ферма: целые гривны списываются с баланса бота, на привязанную по Telegram ID ферму начисляется столько же монет. Ферма → бот: целые монеты списываются, гривневый баланс увеличивается по курсу 1:1. Для обратного перевода нужен свободный резерв выплат. При недостатке резерва ни один баланс не меняется. Аккаунт связывается существующей кнопкой в профиле фермы.

Вывести → сумма → реквизиты → подтверждение. До подтверждения средства не резервируются. После подтверждения сумма резервируется в одной ожидающей заявке. Повторная заявка до закрытия первой запрещена. Можно отменить ожидающую заявку. Положительный статус «Выплачено» ставится только после фактической ручной выплаты.

## Администратор

Используется существующая проверенная личность владельца фермы. /admin → Управление заданиями и балансами либо /botadmin. Новые пользователи административных прав не получают.

- /botcredit TelegramID Сумма УникальныйНомерПлатежа [main|ads] — учесть фактически полученное пополнение. main — основной баланс (по умолчанию), ads — рекламный. Игрок должен сначала открыть бота. Одинаковый номер платежа нельзя учесть повторно.
- /botfund Сумма УникальныйНомерВзноса — учесть реальные собственные средства, выделенные в свободный резерв. Команда не переводит деньги сама и не зачисляет их игроку.
- /botpaid НомерЗаявки НомерБанковскойОперации — подготовить подтверждение уже выполненной выплаты. Проверить сумму/реквизиты и подтвердить кнопкой. Повторно отметить выплату или использовать тот же номер банковской операции нельзя.

Начальный резерв равен нулю: бот не создаёт обеспеченные гривны из стартовых монет фермы автоматически. Все команды учёта требуют фактического финансового основания. Пополнение рекламодателя пока согласовывается с администратором через запрос поддержки, автоматического эквайринга нет. Команда /tickets открывает обращения, /reply отвечает на обращение. Не пересылать CVV, PIN, пароли или коды.

Подписки на модерации и выплаты видны в /botadmin. При отклонении задания/выплаты резерв возвращается на баланс. Выполненные задания и выплаты видны в истории кабинета.

Партнёрская ссылка учитывает новых приглашённых пользователей и тех, кто выполнил задание. Денежные проценты в боте не назначены: автоматических партнёрских выплат нет. Ресурсные рефералы фермы остаются отдельной программой.

## Проверки

`python -m unittest discover -s tests -q`

Тесты task_bot выполняют SQL-сценарии на изолированной SQLite с адаптацией синтаксиса блокировок/JSON. Это проверяет маршруты, проводки, бюджеты, возвраты, права и повторную доставку. Не является проверкой PostgreSQL под конкурентной нагрузкой. Для PostgreSQL используются транзакционные advisory locks и ограничения БД; нагрузочная проверка остаётся отдельной задачей.
